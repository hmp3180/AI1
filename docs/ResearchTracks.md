```

  ⇒ 📏 실측: 한 문서가 **4,159줄**이 됐다 ⇒ `ML`·`SLM` 이 같은 자리에서 같은 갈림을 했다

⇒ ★ 갈림: **개념(왜·경계)** ↔ **정본(지금 참인 값·판정)** ↔ **과정 기록(회차·시간순·안 줄인다)**
⇒ ★ 이기는 쪽: 숫자가 갈리면 **로그**가 이기고, 판정이 갈리면 **정본 `.md`** 가 이긴다

   이 브랜치의 사본은 낡았을 수 있고, 🧾 *"이 브랜치에 없다" 는 부재의 증거가 아니다*

    ⇒ 🧾 ***자리가 없는 것은 두 번 잃는다***)
⚠️ 그리고 **문서를 줄번호로 인용하지 마라** — 절 제목으로 가리킨다
```
